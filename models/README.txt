放置你自己的 3D 模型
====================

支持格式：.glb / .gltf / .obj（GLB 最省事，单文件带贴图）

自动加载
--------
把模型命名为  aircraft.glb   放在本目录（models/），刷新面板即可。
也可以手动指定：  http://127.0.0.1:8123/?model=models/你的模型.glb

朝向约定
--------
· 机头朝 +Z，机背朝 +Y，原点大致在机身中心
· 模型会自动居中、缩放到合适大小（最长边 7.2 单位）
· 如果机头方向不对，用  ?modelYaw=180 （或 90 / -90 / 270）旋转

性能建议
--------
· 三角面 < 15 万，贴图 <= 2048，文件 < 8 MB（60 MB 那种会卡）
· 模型内不要带相机、灯光、动画（会被忽略但白占内存）

从《战争雷霆》拿模型
--------------------
1) 官方资产：游戏目录（如 D:\SteamLibrary\steamapps\common\War Thunder）
   里是 Dagor 的打包资源，需要 CDK + "Dagor Asset Explorer" 之类的工具导出，
   再进 Blender 导出 glTF。B站/YouTube 搜 "Dagor Asset Explorer 导模型" 有教程。
2) 现成资源：Sketchfab 搜 "War Thunder"，不少是玩家从游戏里导出的，
   下载后导出成 glb 放进本目录即可。
   注意：战雷的机体模型版权归 Gaijin，仅限自己本地/私用，别二次分发。

加载失败会静默回退到内置的程序化战机。
